Series Correlation Analysis

Explore relationships between different indicators, categories, pillars, and datasets using multiple statistical analysis modes.

Analysis Modes

First Differences

Examines how year-over-year changes in one variable relate to contemporaneous changes in the other (Δy against Δx), centered on the origin. Differencing absorbs country-specific fixed effects, so the relationship reflects movement rather than persistent level differences.

Year-by-Year Cross-Sectional

Compares values across countries within a single year. Use the year slider to see how the relationship evolves over time. Controls for temporal effects but requires sufficient cross-sectional variation.

Pooled Correlation

Combines all country-year observations into one analysis, ignoring temporal structure. Provides a simple overall correlation measure but may be misleading if the relationship changes over time.
